# IGRM strict-OOF stacking model

## What the model implements

IGRM is a two-level binary classification model.

The base-classifier layer contains four tree-based algorithms:

- LightGBM
- XGBoost
- Random Forest
- GBDT

Each base classifier uses its own feature subset and outputs a positive-class
probability. The four probabilities are combined into a four-dimensional
meta-feature vector. Logistic regression then integrates these probabilities
to produce the final prediction probability.

The logistic-regression meta-classifier is trained with strict out-of-fold
(OOF) probabilities. For each development sample, its four meta-features are
generated by base classifiers that did not use that sample during
preprocessing, feature ranking, hyperparameter selection, or model fitting.

The training pipeline uses five outer stratified folds. Model configuration
and feature-subset selection are performed using three-fold inner
cross-validation. After the OOF meta-classifier is trained, the four base
classifiers are refitted using the complete development set.

## Environment

The reference model was generated with:

- Python 3.12.4
- NumPy 1.26.4
- pandas 2.2.3
- scikit-learn 1.5.0
- joblib 1.4.2
- XGBoost 2.1.3
- LightGBM 4.6.0

Create and activate a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux or macOS:

```bash
source .venv/bin/activate
```

Install the required packages:

```bash
python -m pip install -r code/requirements.txt
```

## Train the model

Run the following command from the repository root:

```bash
python code/train_strict_oof.py
```

The script reads:

```text
data/train.csv
data/test1.csv
data/test2.csv
```

The final preprocessing objects, feature information, base classifiers, and
OOF-trained logistic regression are saved in:

```text
model_pkl/
```

OOF probabilities, test probabilities, selected parameters, selected
features, data-audit records, and evaluation files are saved in:

```text
results/
```

Training a new model updates the files in `model_pkl/` and `results/`.

## Predict new samples

Use the supplied model package:

```bash
python code/predict.py \
  --input data/test1.csv \
  --output results/new_predictions.csv
```

Windows PowerShell:

```powershell
python code\predict.py --input data\test1.csv --output results\new_predictions.csv
```

The input CSV must contain every feature listed in
`model_pkl/feature_cols.pkl`. Identifier columns (`chr`, `pos`, `ref`, and
`alt`) are retained when present.

The prediction file contains:

- the final IGRM probability;
- the predicted binary label at the default threshold of 0.5; and
- the individual probabilities from the four base classifiers.

A different model directory or classification threshold can be specified:

```bash
python code/predict.py \
  --input PATH/TO/INPUT.csv \
  --output PATH/TO/OUTPUT.csv \
  --model-dir PATH/TO/model_pkl \
  --threshold 0.5
```

## Verify the packaged model

Run:

```bash
python code/verify_release.py
```

This checks the packaged data, OOF records, serialized model components, and
reproducibility of the saved prediction probabilities.
